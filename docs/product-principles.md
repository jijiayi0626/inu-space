# 产品原则

## 1. 我们做的是什么

INU 账号中心是一个真实的账号平台：

- 注册与登录（邮箱密码、GitHub、Google）
- 个人资料与账号关联
- 密码、两步验证、登录保护、安全记录
- 多端登录管理：查看所有在线设备、单独退出、退出其他设备
- 通知偏好与站内消息
- 会员等级与积分
- 协议签署与记录
- 订单与收货地址
- 作为 OAuth 2.0 身份提供方，让第三方应用使用 INU 登录

不是科幻主题、不是太空游戏、不是概念演示。

## 2. 语气

- 平静、清楚、短。
- 说结果，不渲染气氛。
- 不使用感叹号、表情符号、夸张形容词。
- 错误文案说明“发生了什么 + 怎么办”。

示例：

| 不要 | 要 |
| --- | --- |
| 星际网络出现波动 | 网络异常，请稍后重试 |
| 已退出星际通行证 | 已退出登录 |
| 新终端已加入可信列表 | 新设备已添加 |
| 完成星际公民认证 | 完成实名认证 |
| 星能余额不足 | 余额不足 |
| 补给已进入跃迁队列 | 订单已提交，等待发货 |

## 3. 信息架构

```
账号

├─ 积分商城

管理
└─ 管理后台（仅管理员）
```

## 4. 多端登录

必须长期满足：

1. 同一账号可在多个浏览器、多个设备同时登录，互不影响。
2. “登录设备”页展示每个在线会话：设备名、系统、浏览器、位置、IP、登录时间、最近活跃。
3. 当前会话有明确标记，且不能被“退出其他设备”误伤。
4. 每个非当前会话可单独退出。
5. 支持“退出其他设备”，保留当前会话。
6. 修改密码后，除当前会话外全部失效。
7. 会话最长 7 天，过期自动清理；服务端每次请求校验哈希。
8. 新设备登录写入安全记录，并在站内通知中提示。
9. 会话可重命名，方便用户区分设备。
10. 所有会话操作写入安全日志。

## 5. 功能原则

- 每个按钮都有结果：加载态、成功提示、失败原因。
- 每个设置都能持久化，刷新后保持。
- 危险操作二次确认，说明影响范围。
- 空状态给出下一步动作，不只写“暂无数据”。
- 前端能点的，后端必须有接口；后端有接口的，管理台尽量可配置。
- 不做假数据装饰；演示数据必须明确标记为演示。

## 7. 新增功能优先级

1. 多端登录体验完善（会话重命名、登录历史、异常登录提醒）。
2. 账号数据导出与账号注销（真实平台必备）。
3. 通知中心（未读、全部已读、按类型筛选）。
4. 会员与积分规则透明化。
5. 管理台可配置项补齐（站点文案、功能开关、会话策略）。

## 8. 验收

- 新用户能在 3 分钟内完成注册、登录、查看设备。
- 用户能在 2 次点击内退出任意其他设备。
- 所有页面在 360px 宽度下可正常使用。
- 所有页面无科幻词、无感叹号、无表情符号。
